# 2026-10-28 M1 前置：arm64 bionic TLS 布局与门禁修正

> 起因：M1 的 gate 原文写的是 `mrs x0, tpidr_el0; ldr x0, [x0]` 读 "tcb->self"。
> 对照真实 bionic 源码后确认：**arm64 上没有 `TLS_SLOT_SELF`**，TP 指向的 slot 0 是
> **DTV**。这是 x86 的布局，不能照搬。
>
> 源码依据：本机 ROM 树 `/home/duck/NewCode/Android/environment/ROM/bionic`
> （manifest `android-14.0.0_r67` / LineageOS 21）。字段集与
> `aosp-mirror/platform_bionic` 的 `android-13.0.0_r1` 逐项核对，本文件用到的字段
> 偏移一致。

---

## 1. arm64 TLS 槽位（`libc/platform/bionic/tls_defines.h`）

```c
#define MIN_TLS_SLOT (-2)
#define TLS_SLOT_NATIVE_BRIDGE_GUEST_STATE (-2)
#define TLS_SLOT_BIONIC_TLS     (-1)
#define TLS_SLOT_DTV              0
#define TLS_SLOT_THREAD_ID        1
#define TLS_SLOT_APP              2   // 历史上是 errno，Q 之后 errno 在 pthread_internal_t
#define TLS_SLOT_OPENGL           3
#define TLS_SLOT_OPENGL_API       4
#define TLS_SLOT_STACK_GUARD      5
#define TLS_SLOT_SANITIZER        6
#define TLS_SLOT_ART_THREAD_SELF  7
#define MAX_TLS_SLOT              7
```

- TCB 共 10 个指针（slot -2..7），`sizeof(bionic_tcb) = 80`。
- `__get_tls()` 返回 `tpidr_el0`，指向 **slot 0（DTV）**；
  `__get_bionic_tcb()` = `&__get_tls()[MIN_TLS_SLOT]` = TP - 16。
- `__init_tcb()` 里 `TLS_SLOT_THREAD_ID = thread`；`TLS_SLOT_SELF` 只在
  `#ifdef TLS_SLOT_SELF`（x86）时初始化。**arm64 没有 self 槽**。
- errno：`__errno()` 返回 `&__get_thread()->errno_value`（`libc/bionic/__errno.cpp`），
  不是 `[TP+16]`。
- 栈保护：slot 5（TP + 40），由 `__init_tcb_stack_guard` 写入。

## 2. `pthread_internal_t`（arm64 LP64，Android 13/14）

按 `libc/bionic/pthread_internal.h` 的字段顺序，用等价类型在宿主上算出偏移
（`pthread_attr_t` 56 字节、`sigset64_t` 8 字节、`Lock` 8 字节）：

| 字段 | 偏移 |
|---|---|
| `next` / `prev` | 0 / 8 |
| `tid` | 16 |
| `cached_pid_` / `vforked_` 位域 | 20 |
| `attr` | 24 |
| `join_state` | 80 |
| `cleanup_stack` | 88 |
| `start_routine` / `arg` / `return_value` | 96 / 104 / 112 |
| `start_mask` | 120 |
| `alternate_signal_stack` | 128 |
| `shadow_call_stack_guard_region` | 136 |
| `stack_top` | 144 |
| `terminating` | 152 |
| `startup_handshake_lock` | 156 |
| `mmap_base` / `mmap_size` | 168 / 176 |
| `mmap_base_unguarded` / `mmap_size_unguarded` | 184 / 192 |
| `vma_name_buffer[32]` | 200 |
| `thread_local_dtors` | 232 |
| `current_dlerror` | 240 |
| `dlerror_buffer[512]` | 248 |
| `bionic_tls*` | 760 |
| `errno_value` | 768 |
| `sizeof` | 776 |

M1 只初始化其中必要字段：`tid`、`cached_pid_`、`stack_top`、`bionic_tls`、
`errno_value`；其余清零，等真实目标读到时再补语义。

## 3. M1 TLS 实例布局

一次 `map(0x4000, RW, "tls")`，内部：

```text
+0x000  bionic_tcb（10 个指针，80 字节）
+0x100  DTV（清零；DTV[0] 是 generation）
+0x200  bionic_tls（0x3000，清零）
+0x3200 pthread_internal_t（0x400，只填必要字段）
```

- `TP = region_base + 0x010`（`+0x000` 是 slot -2，`+0x010` 是 slot 0 = DTV）。
- slot -1 = bionic_tls 地址；slot 1 = pthread_internal_t 地址；slot 5 = stack guard。
- 装载代码后，由 backend 写 `UC_ARM64_REG_TPIDR_EL0 = TP`。

## 4. Gate `01_tls_read` 的修正

原文“`mrs x0, tpidr_el0; ldr x0, [x0]` 读到 tcb->self”不成立。改为验证：

| 读法 | 期望 |
|---|---|
| `mrs x0, tpidr_el0` | TP，等于 TLS 实例的 thread pointer |
| `ldr x1, [x0]` | DTV 指针（slot 0），非空、已映射 |
| `ldr x2, [x0, #8]` | pthread_internal_t*（slot 1），非空、已映射 |
| `ldr w3, [x2, #768]` | errno_value（初始 0） |
| `ldr x4, [x0, #56]` | stack guard（slot 5），非零 |
| `ldr x5, [x0, #-8]` | bionic_tls（slot -1），等于 `[thread + 760]` |

`02_pure_native` 保持“裸 blob 跑完”的目标，额外覆盖 mmap/munmap/mprotect、
write、getpid/gettid、thunk 调用和 exit_group。

## 5. 其他 M1 决定

- Unicorn 页大小在 `uc_open` 后、第一次 map/run 前设为 `0x1000`（M0 实测默认
  0x400）。
- 内存的每个 region 用 `uc_mem_map_ptr` 映射；host 后备是 RW（宿主可信），guest
  权限由 region 的 perms 和 Unicorn 各自决定。
- guest 写可执行页：backend 的 `UC_HOOK_MEM_WRITE` 查 region perms 后
  `uc_ctl_remove_cache`；宿主写代码页走 `CodeWriteNotifier`。
