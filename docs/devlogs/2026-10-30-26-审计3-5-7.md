# 审计 #3 / #5 / #7：readlinkat、RNG 注入、statfs

> 日期：2026-10-30
> A 组剩余三项（#6 io 变体与 #8 ioctl 按计划不做；#2 目录 fd 另行处理）。

## 1. readlinkat(78)

只建模 `/proc/self` 这一组 magic link，其余路径按"存在但不是链接"回答 EINVAL：

| 路径 | 结果 |
|---|---|
| `/proc/self`、`/proc/<pid>` | 进程号字符串 |
| `/proc/self/exe`、`/proc/<pid>/exe` | `DeviceProfile::executable_path`（默认 `/system/bin/app_process64`） |
| `/proc/self/cwd`、`/proc/self/root` | `/` |
| `/proc/self/fd/N` | 打开描述的目标；已关闭 → ENOENT |
| 其它存在的路径 | EINVAL |
| 不存在的路径 | ENOENT |

`/proc/self/fd/N` 的目标按描述类型给：普通/合成文件给 guest 路径，
pipe → `pipe:[inode]`，eventfd/timerfd/epoll → `anon_inode:[...]`。
`readlinkat` 的缓冲区语义照内核：不写 NUL、超长静默截断、`bufsiz == 0` 返回 EINVAL。

`executable_path` 进了 `DeviceProfile`：它和进程名、fingerprint 一样属于设备画像
（app 进程是从 zygote fork 出来的，所以是 `app_process64`）。

## 2. RNG 注入（#5）

`RandomSource` 现在接受种子，`RuntimeConfig::random_seed`（可选）决定实例的流：

- `getrandom(2)`、`/dev/urandom`、`/dev/random` 共用这条流；
- `AT_RANDOM` 也从这条流取（`BionicGlobalsConfig::random`），因此
  `__stack_chk_guard` 也随种子固定；
- 不传种子时仍用宿主熵，行为与之前一致。

CLI 贯通：worker `--random-seed N`，system `--app ...,random-seed=N`。

测试用 `/proc/self/auxv` 找到 AT_RANDOM 的地址读回 16 字节，比较同种子/异种子的
两个实例。

## 3. statfs(43) / fstatfs(44)

`struct statfs`（arm64）120 字节：type/bsize/blocks/bfree/bavail/files/ffree/fsid/
namelen/frsize/flags + spare。`FileSystemStats` 由 VFS 按路径归类：

| 路径 | 类型 | 说明 |
|---|---|---|
| `/data` 及其下 | `DeviceProfile::data_file_system_type`（默认 f2fs） | 容量/可用来自画像 |
| `/system`、`/vendor`、`/product`、`/odm`、`/` 等 | erofs | `f_flags` 带 ST_RDONLY |
| `/dev` 及其下 | tmpfs | 含 `/dev/__properties__` |
| `/proc` 及其下 | proc | |
| pipe fd | pipefs | fstatfs |
| eventfd/timerfd/epoll fd | anon_inode | fstatfs |

`DeviceProfile` 新增 `data_file_system_type` / `data_total_bytes` /
`data_free_bytes`（默认 f2fs、64 GiB / 32 GiB）；安装、更新类目标探测的就是这组值。

## 4. 测试

- `04k_readlink`：exe/cwd/root/self、`/proc/<pid>/exe`、`fd/N`（打开与关闭后）、
  EINVAL/ENOENT、`bufsiz == 0`、截断。
- `04l_random_seed`：同种子两实例的 `/dev/urandom`、`getrandom`、`AT_RANDOM`
  逐字节相同，异种子不同；同一实例内不同表面取到不同字节。
- `04m_statfs`：`/data` 类型与扇区数来自画像、`/system` 是只读 erofs、
  `/proc` 是 proc、`/dev/null` 的 fstatfs 是 tmpfs、pipe fd 是 pipefs。

全量 **44/44**。
