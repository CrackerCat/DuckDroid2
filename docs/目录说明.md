```text
duckemu/
├── CMakeLists.txt
├── cmake/
│   ├── CompilerWarnings.cmake
│   ├── Sanitizers.cmake
│   └── FindUnicorn.cmake
├── third_party/ 可选，如果是真的必要，需要向我打报告，咱们商量
│   ├── unicorn/
│   ├── dynarmic/            # 第二次重构时才接，目录先预留
│   ├── fmt/
│   ├── spdlog/
│   └── gtest/
├── include/duckemu/         # 对外公共头（runtime 作为库被外部引用时用）
├── src/
│   ├── common/              # 全工程共享：ID、错误、日志、UDS 封装、同步原语
│   ├── protocol/            # UDS 通信协议定义（HTTP/1.1 最小子集 + 内部消息）
│   ├── runtime/             # ★ 核心：RuntimeInstance 及其全部子系统（= Emulator）
│   ├── worker/              # WorkerProcess：RuntimeInstance 池、MemoryPool、宿主线程池
│   ├── system/              # System：UDS 前端、路由、WorkerPool、PrimordialProcess
│   └── web/                 # 可选；推荐独立仓库，本仓库只放协议参考实现
├── tests/
├── tools/
├── configs/
└── docs/
```

❌ 禁止出现 src/host/、src/guest/、src/vmm/、src/hypervisor/。

❌ 禁止把 memory/、threads/、jni/ 提到 src/ 顶层与 runtime/ 并列。

❌ 禁止把 backend/ 放在 worker/ 下——backend 归 RuntimeInstance。

❌ 禁止在 runtime/ 里再加一层 emulator/ 或 instance/instance/。

❌ 禁止按 syscall 名分文件成 runtime/svc/mmap.cpp、runtime/svc/futex.cpp 这种碎法（见 §4.5）。

❌ 禁止 RuntimeInstance 暴露 getMemory()、getThreads()——门面就是门面。

# 四、src/runtime/ — 核心，RuntimeInstance 及其全部子系统

这是最重要的目录。RuntimeInstance 就是 DuckEmu 的 Emulator，所有补环境语义都在这棵树的根上。

```text

├── instance/            # ★ RuntimeInstance 门面本身
│   ├── runtime_instance.hpp        # 对外接口：loadLibrary / callFunction / mem_* / hook / ...
│   ├── runtime_instance.cpp
│   ├── state_machine.hpp           # Created → Ready → Executing → ... → Destroyed
│   ├── state_machine.cpp
│   └── factory.hpp                 # RuntimeInstance::create(config)
│
├── memory/              # RuntimeMemoryManager：Guest 地址空间唯一权威
│   ├── address_space.hpp
│   ├── address_space.cpp           # Guest VA → 宿主后备的映射
│   ├── region.hpp                  # 区域、权限、归属、OwnerTag
│   ├── mmap_ops.cpp                # mmap / munmap / mprotect / MAP_FIXED 语义
│   ├── code_notifier.hpp           # CodeWriteNotifier 接口（被 backend 实现）
│   └── code_notifier.cpp           # 写代码页时调 backend->invalidate_code()
│
├── threads/             # RuntimeThreadScheduler：futex 驱动
│   ├── runtime_thread.hpp          # 可剥夺执行上下文
│   ├── scheduler.hpp
│   ├── scheduler.cpp               # run_queue / yield / budget 移交
│   ├── futex/
│   │   ├── wait_queue.hpp
│   │   ├── wait_queue.cpp
│   │   └── futex_ops.cpp           # FUTEX_WAIT / FUTEX_WAKE
│   ├── clone/

│   │   ├── clone_impl.cpp          # CLONE_SETTLS / CLONE_CHILD_CLEARTID
│   │   └── clear_child_tid.cpp
│   └── tls/
│       ├── tls_layout_android12.hpp   # 按 bionic 源码抄的 TCB/DTV 布局
│       ├── tls_layout_android13.hpp
│       ├── tls_layout_android14.hpp

├── vfs/                 # RuntimeVFS：per-RuntimeInstance 文件视图
│   ├── runtime_vfs.hpp
│   ├── runtime_vfs.cpp
│   ├── file_handle.hpp
│   └── backends/
│       ├── host_fs_backend.cpp      # 从宿主文件系统读
│       └── apk_backend.cpp          # 从 APK 读（后期接）

│   ├── event_bus.cpp

│   │   ├── module_event.hpp
│   │   └── memory_event.hpp

│       ├── insn_snapshot.hpp

    ├── backend_factory.cpp
    ├── unicorn/
    │   ├── unicorn_backend.hpp

    │   └── unicorn_code_notify.cpp  # UC_CTL_TB_REMOVE_CACHE

        ├── dynarmic_backend.hpp
        ├── dynarmic_backend.cpp
        ├── dynarmic_code_notify.cpp # 已翻译 VA 区间 → block 索引 + 清缓存
        └── dynarmic_jit_cache.cpp   # JIT cache 自管 mmap
```

几个关键点：

instance/ 是门面，runtime_instance.hpp 只放 §5.2 那份接口，不放实现细节。

memory/ 不拥有 backend。code_notifier.hpp 定义回调接口，backend 实现，RuntimeInstance 在 initialize 时接线。

threads/tls/ 按 Android 版本分文件，不硬编码示意字节。

svc/handlers/ 按子系统分文件，不按 syscall 碎。每个 handler 文件内部是 switch(imm) 分发到具体实现。

backend/unicorn/ 和 backend/dynarmic/ 是对等实现，不共享内部细节，只共享 execution_backend.hpp 接口。

observer/semantic/ 同步，observer/diagnostic/ 异步，两条通道物理分离。
